# Лаборатори №1: UI автомат тест — Playwright

Энэхүү лабораторийн ажлаар Playwright хэрэгслийг ашиглан `saucedemo.com` демо веб сайт дээр UI автомат тестүүдийг бичиж гүйцэтгэлээ.

## Гүйцэтгэсэн ажлууд

1.  **Playwright орчин бэлдэх**: Kali Linux дээр Playwright-ийг суулгаж, шаардлагатай системүүдийн сангуудыг (dependencies) тохируулсан.
2.  **Тест скрипт бичих**: `tests/mytest.spec.ts` файлд дараах 3 тестийг бичсэн:
    *   Амжилттай нэвтрэх (Positive test)
    *   Амжилтгүй нэвтрэх (Negative test - буруу нууц үг)
    *   Бараа сагсанд нэмэх (Functional test - нэвтэрсний дараах үйлдэл)
3.  **Locator-ууд**: Тестэд `getByRole`, `getByPlaceholder`, `getByText` зэрэг орчин үеийн locator-уудыг ашигласан.
4.  **Trace Viewer**: Тестийн алхам бүрийг trace viewer ашиглан баримтжуулсан.

## Playwright ба Selenium харьцуулалт

Playwright болон Selenium нь хоёулаа UI автоматжуулалтын хүчтэй хэрэгслүүд боловч Playwright нь илүү орчин үеийн давуу талуудтай. Миний ажигласнаар:
*   **Auto-wait**: Playwright нь элемент бэлэн болтол автоматаар хүлээдэг нь кодыг илүү ойлгомжтой, тогтвортой (less flaky) болгож байна. Selenium дээр explicit wait-ийг гараар бичих шаардлагатай болдог.
*   **Суулгац**: Playwright нь бүх хөтөч болон сангуудыг нэг командаар суулгадаг нь маш амар. Selenium-д хөтөч бүрд тохирсон driver-уудыг гараар удирдахад төвөгтэй байдаг.
*   **Хурд**: Playwright нь параллель тест ажиллуулахдаа маш хурдан бөгөөд "Context" ашиглан хөтөчийг дахин дахин нээхгүйгээр тусгаарлагдсан тестүүдийг ажиллуулж чаддаг.
*   **Trace Viewer**: Алдаа гарсан үед Playwright-ийн trace viewer-ээр DOM snapshot болон видеог үзэх нь асуудлыг оношлоход Selenium-ээс хавьгүй илүү байна.
